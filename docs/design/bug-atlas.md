## What each class means for Pintail

- **Planner and rewrite wrong results** - Subquery decorrelation, derived-table merging, predicate pushdown, join reordering and outer-join simplification returning different rows.
- **Replication apply and position tracking** - Applying changes in order, restart and resume positions, GTID sets, skipped or duplicated transactions, purged logs.
- **Type inference and comparison coercion** - Result types of expressions, mixed-type comparison, CAST, IN/BETWEEN comparison types.
- **Client protocol** - Handshake, authentication, result metadata, prepared statements, text and binary encodings, client compatibility.
- **Binary log events and decoding** - Row event decoding, type encodings in row images, metadata, compressed payloads, GTID and rotation events.
- **Schema changes under a live mirror** - ALTER, RENAME, TRUNCATE and type changes arriving through the change stream; DDL parsing; row images after a schema change.
- **Crash recovery and durability** - Write-ahead logging, torn writes, fsync, partial files, restart with inconsistent metadata.
- **Concurrency between readers, writers and background work** - Races between queries, ingestion, merges, schema changes and shutdown; lock ordering; use-after-free on shared state.
- **Aggregation and grouping** - GROUP BY semantics, aggregate state, DISTINCT, ROLLUP, HAVING, empty and NULL groups.
- **Dates, times and time zones** - Temporal parsing, zero and negative values, fractional seconds, time zone conversion, interval arithmetic.
- **String and scalar functions** - Scalar function semantics at edges: NULL, empty, binary, multi-byte, overflow.
- **Character sets and collations** - Equality, ordering, grouping, LIKE and padding under a collation; charset conversion.
- **Skip indexes and pruning** - Min/max statistics, key-range analysis and pruning that skips data it should have read.
- **Join execution** - Hash, merge and nested-loop join operators: NULL keys, spilling, outer padding, duplicates.
- **Initial copy and snapshot handoff** - Consistent initial copy, chunked reads, the handoff position between copy and stream.
- **JSON values** - JSON parsing, path evaluation, comparison and serialization.
- **Sorting, top-k and spilling** - Ordering stability, top-k, external sort, memory limits during sort.
- **Exact numeric arithmetic** - DECIMAL precision, scale, rounding, overflow and conversion to and from text or floats.
- **Window functions** - Frame bounds, peers, partition boundaries and ordering inside windows.
- **Memory and resource limits** - Accounting, spilling, cancellation and out-of-memory behaviour under limits.
- **Immutable parts, merges and versioned deduplication** - Background merges of sorted runs, version-resolving reads, tombstones and overlap between runs.
- **On-disk format, encodings and compression** - Encoders, codecs, checksums, file layout and format evolution.
- **Floating-point formatting and parsing** - Shortest round-trip printing, exponent forms and float/text conversion.
- **Catalog and metadata views** - information_schema contents, SHOW commands and metadata clients depend on.
