# M2 query engine

Pintail now owns the complete in-process query path from MySQL-dialect parsing
through typed binding, logical planning, rule optimization, physical
planning, and pull-based vectorized execution over reader-pinned PTSEG
snapshots. Stable catalog identities survive aliases and projection pruning;
execution uses nullable column vectors, shared selection masks, approximately
4K-row batches, a hard query-memory budget, and deterministic physical plans.

The implemented relational surface includes scans, filters, projections,
distinct, grouped and global hash aggregation, inner/left/semi/anti hash
joins, guarded cross joins, full and top-K sorting, limits, streaming
`UNION ALL`, derived tables, uncorrelated scalar and `IN` subqueries, and
non-recursive CTEs. The MySQL scalar, aggregate, string, conditional,
date/time, cast, and predicate functions listed for M2 are bound to typed
expressions with three-valued NULL behavior. Catalog metadata serves
`SHOW`, `DESCRIBE`, and basic `information_schema` views.

The rule optimizer performs constant folding, safe predicate pushdown,
stable-ID projection pruning, cardinality-based cross-join ordering, safe
limit propagation, exact metadata substitution for predicate-free
`COUNT(*)`, and proof-limited aggregate pushdown. Storage scans translate
supported single-key predicates into physical ranges, prune segments and key
blocks, late-materialize requested columns, and parallelize independent
segment work on a dedicated worker pool. `EXPLAIN` shows the physical shape;
`EXPLAIN ANALYZE` adds actual segment, key-block, and decoded-block counters.

## Gate evidence

- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace --locked`
- `cargo test -p pintail-sqllogic --test plan_quality`
- `cargo test -p pintail-sqllogic --test mysql_oracle -- --ignored --nocapture`
- `bun install --frozen-lockfile`, `bun run typecheck`, and
  `bun run generate` in `packages/dashboard`
- 600 deterministic queries matched MySQL 8.4 over equivalent seeded tables
  across arithmetic/predicates, strings and conversion, conditionals/NULLs,
  date/time, constant and table-reading subqueries, CTEs, scans/sorts, the
  complete aggregate family, hash joins, and `UNION ALL`
- the physical plan-quality test proved a selective primary-key predicate
  read one of two segments and one of two logical key blocks

M2's intentionally unsupported or approximate compatibility corners are
listed in [`docs/limitations.md`](../limitations.md). This milestone does not
claim the later snapshot, CDC, polling, API, wire-protocol, backup, soak, or
benchmark gates.
