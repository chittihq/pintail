# M7 MySQL wire protocol

Pintail now serves its native MySQL-dialect query engine on a configurable
wire endpoint, `127.0.0.1:3306` by default. The database name is the username
and a database-scoped API key with `query` scope is the password. Each
connection uses a random native-password challenge; Pintail persists only the
double-SHA-1 protocol verifier alongside the existing SHA-256 bearer lookup
digest, never the plaintext key.

Text commands and prepared statements execute through the same reader-pinned
`ReplicaEngine` as HTTP. The server exposes typed bounded results, physical
scan statistics through the shared engine, catalog-backed `SHOW`, `DESCRIBE`,
and `information_schema`, EXPLAIN, common BI capability probes, and explicit
read-only errors. Binary prepared results retain narrow numeric, exact decimal,
date, datetime, signed time, JSON, UTF-8, and binary encodings.

The binary binds HTTP and wire listeners before serving either and shuts both
down from one signal. `/status` reports the actual bound wire address. The
dashboard's Settings page shows that live endpoint, while Connect generates
complete MySQL CLI, Bun/mysql2, and PyMySQL examples plus DBeaver and Metabase
connection fields.

## Gate evidence

- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo test --workspace --locked`
- `PINTAIL_EXTERNAL_WIRE_CLIENTS=1
  PINTAIL_MYSQL_CLI=/opt/homebrew/opt/mysql-client@8.4/bin/mysql
  cargo test -p pintail-wire --test wire_compat -- --nocapture`
- `bun install --frozen-lockfile`, `bun run typecheck`, and
  `bun run generate` in `packages/dashboard`
- Playwright first-boot/login, Settings, and Connect checks at desktop and
  390-pixel mobile widths with zero browser errors or warnings

The compatibility gate exercises `mysql_async`, a real MySQL 8.4 CLI, mysql2
under Bun, and PyMySQL. It covers database selection, native challenge success
and rejection, session setup, text and prepared queries, metadata discovery,
BI-style aggregates, EXPLAIN, typed binary fidelity, normalized zero dates,
and clean write rejection. Oracle's MySQL 9.x CLI no longer ships the native
password client plugin; Pintail intentionally does not weaken authentication
to accommodate that removal.
